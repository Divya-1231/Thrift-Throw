# 🛍️ Thrift Throw

A modern and responsive thrift shopping website built using **HTML5** and **CSS3**. This project provides a clean and user-friendly interface for browsing second-hand products, promoting sustainable fashion through an attractive web design.

## ✨ Features

* Responsive design for desktop, tablet, and mobile
* Modern hero section
* Product categories
* Featured product cards
* Smooth navigation
* Clean and attractive UI
* Optimized layout with Flexbox and CSS Grid

## 🛠️ Technologies Used

* HTML5
* CSS3
* Google Fonts
* Font Awesome
